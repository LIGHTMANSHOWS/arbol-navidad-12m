# LIGHTMAN · Árbol musical de Navidad · 12 metros

[**Abrir el visualizador público**](https://lightmanshows.github.io/arbol-navidad-12m/)

Árbol navideño interactivo en 3D: 12 m de altura total, Ø 7,5 m de base, 64 líneas y 9.696 píxeles RGB. Show de tres minutos con Jingle Bells, Deck the Halls y We Wish You a Merry Christmas, en arreglos instrumentales sintetizados para este proyecto.

La web y todos sus archivos se alojan directamente en **GitHub Pages**, sin inicio de sesión ni dependencia del alojamiento de Sites para reproducir el show. Pulsa **Vivir el espectáculo** para iniciar música y luces. Puedes girar el modelo, cambiar perspectiva, avanzar entre canciones y revisar la propuesta.

- [Proyecto descargable ZIP](https://lightmanshows.github.io/arbol-navidad-12m/assets/proyecto-navidad-12m.zip)
- [Máster musical WAV](https://lightmanshows.github.io/arbol-navidad-12m/assets/navidad-lightman.wav)
- [Propuesta imprimible](https://lightmanshows.github.io/arbol-navidad-12m/proyecto.html)

El ZIP incluye la web, MP3, FSEQ, geometría, patch, propuesta, documentación y scripts reproducibles. El máster WAV se descarga por separado desde esta web. El ZIP completo entregado en el chat también incluye el WAV.

Los precios son una estimación de planificación, no ofertas de proveedores. La estructura, distribución eléctrica y el patch son propuestas que requieren validación en el montaje. El navegador simula las luces; no emite Art-Net.

Motor Three.js bajo licencia MIT; avisos en LICENSES.txt. Música, créditos y referencias en show.json.
